# AutoBoss

Minecraft 1.21.1 Fabric 客户端模组：自动识别公屏头目公告，进入对应镇线/层数，并沿固定飞行路线跑到头目坐标。

## 用法

| 按键 | 作用 |
|---|---|
| `B` | 打开 AutoBoss 菜单 |
| `=` | 强制终止所有流程，并关闭自动识别（防止下一条公告又启动，B 菜单可重开） |

菜单里可以开关自动识别、调试日志、奖励消息屏蔽、副本组（A/B），可以点「开始（最近识别）」用最近一条公告启动（不受自动识别开关影响），也可以终止当前流程。

## 识别规则

公屏公告必须同时包含：

- 线路：`新三线` / `新五线` 之类
- 层数：`F15` 之类（只处理 F10 / F12 / F13 / F14 / F15，F11 直接忽略）
- 坐标：`x:.. y:.. z:..`

解析和调试日志都写在 `logs/latest.log` 里（`[autoboss]` 前缀）。识别成功后会：

1. `/menu` → 点「魔塔」→ 点「魔塔镇新线路N」
2. 传送到镇线后，先走与猪核一致的三段飞行到 `(-15,187,-57)`：平飞 2.5 格 → 抬头 -89° 拉升到 Y=187 → 水平接近
3. 到中转点后 `goto` 导航点，等 2 格内（超时 200 tick 放过），再 `goto` 一次，等 2 格内（超时 150 tick 放过）
4. 静止校准 dx/dz 都 < 2.5（失败重来最多 2 次），对准并右键告示牌；15 tick 内没打开菜单就回第 3 步重试一次
5. 右键告示牌 →（13/14/15c 先点特殊层槽位）→「A组副本」→「传送第X层一线」
6. 进本后按路线逐点飞行，到最后一个点停止寻路并关闭飞行

三段飞行 150 tick 没到中转点会重进一次镇线；再失败就中止。自动流程只处理一条公告，没有「跳下一条线」的循环，失败即报错停止。

只选「一线」，不会抢 A1/A2/A3，也不会自动打怪——到点后就停下，战斗交给玩家。

## 跑图路线

| 层 | 路线 |
|---|---|
| 10c | `127 108 -226` → `-30 132 -226` → 头目坐标 |
| 12c | `105 76 92` → `105 112 92` → `143 112 23` → 头目坐标 |
| 13c | `-22 38 -141` → `-32 38 -92` → 头目坐标 |
| 14c | `-78 14 0` → 停寻路+停飞行 → 下坠 3 秒 → 落地后直线走到 `x=-70` → 重开飞行 → `-58 38 20` → 头目坐标 |
| 15c | `-45 14 -49` → `7 14 -49` → 头目坐标 |

所有路线到达头目坐标后都会**停寻路并关闭飞行**（自由下坠），不会保持悬停。14c 中途那次关飞行是例外：下坠 3 秒后会重新开飞行继续跑。

坐标来自头目公告原文。层数告示牌坐标当前沿用猪核：10c `-12 164 -73`、12c `-12 184 -73`、13/14/15c `-12 194 -73`；如果新地图换了位置，改 `AutoBossController.signPos()` / `navPos()`。
